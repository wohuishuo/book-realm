# UI Pattern Library

## 书架

使用微信读书模式：顶部固定搜索入口与页面动作，下方使用排序/筛选行，主体为稳定三列封面网格，底部为一级导航。加载标签、角标和长书名不得改变网格轨道尺寸。

## 阅读器

正文全屏、无卡片容器。顶部栏与底部工具栏默认隐藏；正文宽度、页边距和行距由 token 与用户设置控制。点击中央切换工具栏，左右区域只在明确分页模式下翻页。

## 文字选择

采用微信读书模式：选区附近显示紧凑操作栏，提供复制、划线、笔记、词典/翻译、AI；颜色和划线样式放入第二级紧凑面板。操作栏不覆盖选区，屏幕边缘自动换位。

## 阅读设置

采用底部面板，字号用步进或滑杆，背景用色板，行距/边距/翻页模式用 segmented control。面板展开不改变当前段落锚点。

## 目录

优先微信读书的层级列表与当前章节高亮；当章节数量大、包含分卷或需要排序时，采用起点的目录筛选与固定底部动作。目录项固定最小高度 `48dp`，当前章节自动滚入视野。

## AI 阅读助手

采用起点未被微信读书覆盖的全屏/底部对话模式：保留顶部返回与上下文书名，内容区显示回答和原文引用，输入栏固定于键盘上方。建议问题使用列表，不使用装饰性大卡片；回答必须能跳回引用段落。

## 组件预览清单

`BrPrimaryButton`、`BrTopAppBar`、`BrBottomNavigation`、`BrBookGridItem`、`BrReaderToolbar`、`BrReaderSettingsSheet`、`BrSelectionMenu`、`BrChapterRow`、`BrAiComposer` 必须各有 Preview。页面实现只能组合这些组件；缺少能力时先扩展模式库。
