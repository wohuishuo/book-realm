# Android UI Rules

## Navigation

- 底部导航只保留书架、书城、我的三个一级入口。
- 阅读页不显示底部导航。
- 从书架进入阅读器时返回书架。
- 从详情目录进入阅读器时返回详情。
- 返回键优先关闭临时面板,再离开当前页面。

## Reader

- 阅读页默认隐藏顶部和底部操作栏。
- 点击正文空白区域切换操作栏显隐。
- 字号、行距和背景主题必须可配置并持久化。
- AI 回答使用临时窗口,不插入或修改正文。
- 划线选择使用浮动工具条,不使用覆盖正文的大型底部面板。
- 顶部工具栏必须避让状态栏和刘海区域。

## Feedback

- 网络失败显示重试入口。
- 离线缓存命中时正文正常显示。
- 删除、复制、保存等动作给出简短反馈。
- AI 或统计服务失败不得导致阅读器退出。
