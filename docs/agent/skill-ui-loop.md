# Skill: UI Loop

## 顺序

1. 读取 PRD Journey 与 `docs/ui/` 规则。
2. 先在微信读书参考中找同类模式；没有对应功能时才查起点。
3. 只组合设计系统组件和 token，禁止行内样式、任意 dp/sp、临时颜色和重复组件。
4. 实现加载、空、错误、禁用、离线和长文本状态。
5. 跑 Android lint、单测与构建，在真实设备或截图测试检查浅色/深色、紧凑/大字体。
6. 将视觉证据附到 PR；发现新模式先更新设计系统，再使用它。

## 完成标准

顶部栏、底部栏、触控区和正文节奏符合固定 token；阅读页不被卡片化；一个页面最多一个主操作。
