# P4 用例分析

> **结论先行**:用户类型(游客/读者/管理员)与权限,UML 用例图,核心用例规约。

## 一句话结论

**三类用户在书域中各有清晰边界——游客可浏览书城和试读,读者通过 JWT 登录后拥有完整的书架、阅读和 AI 问答能力,管理员负责内容入库与统计查询——三个核心用例(注册登录、打开书阅读、AI 问答)覆盖了全平台主线。**

## 一、用户类型与权限

| 角色 | 说明 | 能做什么 |
| --- | --- | --- |
| **游客** | 未登录用户 | 浏览书城(查看书籍列表与详情)、试读公版书前 N 章、注册账号 |
| **读者** | 已登录用户(JWT) | 游客全部权限 + 收藏书籍到书架、完整阅读所有章节、阅读进度记忆与同步、划词 AI 问答、查阅自己的阅读统计 |
| **管理员** | 已登录且拥有 admin 角色 | 读者全部权限 + 管理书籍(上传/编辑/下架)、查看平台统计数据(登录次数、阅读量) |

## 三、核心用例规约

### 用例一:注册与登录

| 项目 | 内容 |
| --- | --- |
| **用例名** | 注册与登录 |
| **主角色** | 游客( → 读者) |
| **前置条件** | 用户中心服务正常运行;App 可访问用户中心 API |
| **主成功流程** | 1. 游客在 App 登录页输入用户名和密码;2. 点击"注册",App 调用 `POST /api/auth/register`(MVP-0);3. 用户中心校验用户名≥4 位、密码≥6 位、用户名不重复,写入 MySQL,返回成功;4. 游客输入刚注册的凭据,点击"登录";5. App 调用 `POST /api/auth/login`(MVP-0);6. 用户中心校验凭据,生成 JWT,发布 UserLogin 事件到 RabbitMQ(MVP-3);7. 日志服务消费事件落盘;统计服务消费事件更新登录计数;8. App 收到 JWT,存入 DataStore,跳转书架页 |
| **扩展流程** | 3a. 用户名重复 → 返回"用户名已被注册";3b. 格式不合法 → 返回校验失败原因;6a. 用户中心服务不可达 → App 显示"网络错误,请重试" |
| **后置条件** | 读者获得有效 JWT(含角色声明),后续请求携带 Token;登录事件被统计服务记录 |

### 用例二:打开一本书并阅读

| 项目 | 内容 |
| --- | --- |
| **用例名** | 打开一本书并阅读 |
| **主角色** | 读者 |
| **前置条件** | 读者已登录(JWT 有效);书库服务有至少一本书及章节内容 |
| **主成功流程** | 1. 读者在书架点击一本书(或从书城进入详情页);2. App 调用 `GET /api/books/{id}/chapters`(MVP-1),获取章节目录;3. 读者点击某章,App 调用 `GET /api/chapters/{id}`(MVP-1),获取段落结构;4. App 阅读器渲染章节内容(分页/排版——MVP-2 阅读器);5. 读者翻页阅读,App 每翻一页更新本地进度(Room);6. 读者退出阅读器,App 上报 ReadingProgress 事件到书库服务(MVP-2 → MVP-3);7. 读者再次打开 App,书架页显示"继续阅读"卡片(上次读到哪章哪页——MVP-2 最近阅读) |
| **扩展流程** | 2a. 书籍无章节 → 显示"本书暂无内容";3a. 网络不可达 → App 从 Room 缓存读取上次缓存的章节(离线阅读);6a. 事件上报失败 → 重试 3 次,仍失败则静默放弃(不阻塞阅读) |
| **后置条件** | 本地 Room 存储最新进度;服务端记录阅读事件(用于统计"读了多少章") |

### 用例三:AI 读书问答

| 项目 | 内容 |
| --- | --- |
| **用例名** | AI 读书问答 |
| **主角色** | 读者 |
| **前置条件** | 读者已登录;正在阅读某章节;AI 服务与向量库正常运行;当前章节已向量化入库 |
| **主成功流程** | 1. 读者在阅读器中长按选中一段文字;2. 弹出"问问 AI"按钮,读者输入问题(或使用默认"解释这段话");3. App 调用 `POST /ai/ask`(MVP-4),携带:选中文本、章节 ID、读者问题;4. AI 服务将问题向量化,在向量库中检索与问题最相关的段落(MVP-4 向量检索);5. AI 服务将检索到的上下文 + 选中文本 + 问题组装为 prompt,发送给 LLM;6. LLM 生成回答(含原文引用),AI 服务返回给 App;7. App 在阅读器底部弹出问答面板,显示回答和引用的原文出处 |
| **扩展流程** | 3a. AI 服务不可达 → App 显示"AI 服务暂不可用,请稍后";4a. 向量库未覆盖当前章节 → 降级为仅用选中文本 + 问题发送给 LLM(无引用);6a. LLM 返回超时(>10s) → App 显示"回答生成中,请稍候",轮询结果 |
| **后置条件** | 无副作用(问答不持久化);读者获得带原文引用的回答 |

## 用例与 MVP 的对应

| 用例步骤 | 对应 MVP | 对应接口/界面 |
| --- | --- | --- |
| 注册登录 → 调用注册/登录 API | MVP-0 用户中心 | `POST /api/auth/register`、`POST /api/auth/login` |
| 登录成功 → 发布事件 | MVP-3 统计 | RabbitMQ UserLogin 事件 |
| 获取章节目录/内容 | MVP-1 书库 | `GET /api/books/{id}/chapters`、`GET /api/chapters/{id}` |
| 阅读器渲染/进度记忆 | MVP-2 App | Compose 阅读器 + Room 缓存 |
| AI 问答 | MVP-4 AI | `POST /ai/ask` |
| 查看阅读统计 | MVP-3 统计 | 统计查询 API |
