# P4 用例分析

> **结论先行**:三类用户各有清晰边界——游客浏览,读者阅读和提问,管理员管理。三个核心用例覆盖全平台主线,每个步骤都能对应到某个 MVP 的接口或界面。

## 一、用户类型与权限

**结论:三类角色,权限递增,边界清晰。**

| 角色 | 说明 | 能做什么 |
| --- | --- | --- |
| **游客** | 未登录 | 浏览书城、试读前 N 章、注册 |
| **读者** | 已登录(JWT) | 游客全部 + 收藏书架、完整阅读、进度同步、划词 AI 问答、查阅阅读统计 |
| **管理员** | admin 角色 | 读者全部 + 管理书籍(上传/编辑/下架)、查看平台统计 |

**根据**:读者和管理员都继承游客的全部权限。权限校验在用户中心的 JWT role 字段完成,App 根据角色显示不同的界面入口。

## 三、核心用例规约

### 用例一:注册与登录

| 项 | 内容 |
| --- | --- |
| **用例名** | 注册与登录 |
| **主角色** | 游客(→ 读者) |
| **前置条件** | 用户中心正常运行 |
| **主成功流程** | 1. 输入用户名和密码;2. 注册:`POST /api/auth/register`,校验长度/唯一性,BCrypt 加密写入 MySQL;3. 登录:`POST /api/auth/login`,校验凭据,生成 JWT,发布 UserLogin 事件到 RabbitMQ;4. 日志服务落盘,统计服务更新计数;5. App 收到 JWT 存入 DataStore,跳转书架 |
| **扩展流程** | 2a. 用户名重复 → "用户名已被注册";2b. 格式不合法 → 提示具体原因;3a. 凭据错误 → "账号或密码错误"(不暴露是哪个错) |
| **后置条件** | 读者获得 JWT(含角色声明);统计服务记录登录 |

**例子**:这个用例的每一步都对应代码——步骤 2 对应用户中心的 `UserServiceImpl.userRegister`,步骤 3 对应 `userLogin` + `JwtUtils.createToken`,步骤 5 对应 App 的 `DataStore.putString("jwt", token)`。

### 用例二:打开一本书并阅读

| 项 | 内容 |
| --- | --- |
| **用例名** | 打开一本书并阅读 |
| **主角色** | 读者 |
| **前置条件** | 已登录;书库服务有书及章节 |
| **主成功流程** | 1. 点击书架上的书 → `GET /api/books/{id}/chapters` 获取目录;2. 点击某章 → `GET /api/chapters/{id}` 获取段落;3. 阅读器渲染(分页/排版);4. 翻页 → 更新本地进度(Room);5. 退出 → 上报 ReadingProgress 事件;6. 再次打开 → 书架"继续阅读"卡片定位到上次位置 |
| **扩展流程** | 2a. 网络不可达 → 读 Room 缓存(离线阅读);2b. 书籍无章节 → "暂无内容";5a. 事件上报失败 → 重试 3 次,仍失败静默放弃 |
| **后置条件** | Room 存最新进度;服务端记录阅读事件 |

### 用例三:AI 读书问答

| 项 | 内容 |
| --- | --- |
| **用例名** | AI 读书问答 |
| **主角色** | 读者 |
| **前置条件** | 已登录;正在读某章节;AI 服务与向量库运行中 |
| **主成功流程** | 1. 长按选中一段文字;2. 弹出"问问 AI",输入问题;3. `POST /api/ai/ask` 带选中文本+章节 ID+问题;4. AI 服务向量检索(限定当前章节);5. 检索结果+问题组 prompt → LLM 生成回答+原文引用;6. 阅读器底部面板显示回答 |
| **扩展流程** | 3a. AI 服务不可达 → "AI 暂不可用";4a. 向量库未覆盖当前章节 → 降级为仅用选中文本+问题发 LLM |
| **后置条件** | 无副作用(问答不持久化) |

## 用例与 MVP 对应

**结论:每个用例步骤对应一个明确的 MVP 接口或界面。**

| 用例步骤 | MVP | 接口/界面 |
| --- | --- | --- |
| 注册/登录 | MVP-0 用户中心 | `POST /api/auth/register`、`POST /api/auth/login` |
| 登录事件 | MVP-3 统计 | RabbitMQ UserLogin |
| 章节目录/内容 | MVP-1 书库 | `GET /api/books/{id}/chapters`、`GET /api/chapters/{id}` |
| 阅读器/进度 | MVP-2 App | Compose 阅读器 + Room |
| AI 问答 | MVP-4 AI | `POST /api/ai/ask` |
| 统计查询 | MVP-3 统计 | 统计查询 API |
