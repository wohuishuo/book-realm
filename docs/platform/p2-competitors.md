# P2 竞品分析

> **结论先行**:起点读书 / 微信读书 / 番茄小说的功能与体验对比,我们的差异点。

## 一句话结论

**三个竞品各占一个生态位——起点读书是网文付费标杆,微信读书是社交阅读平台,番茄小说是广告换免费——书域不与它们正面竞争,而是用"全流程开源 + RAG 读书问答"服务一个被忽视的场景:在读公版书的同时,用 AI 真正读懂。**

## 二、竞品逐一分析

### 起点读书:段落级书评是壁垒,但我们不碰网文

**起点读书最强的点是"本章说"——读者可以在任意段落发表评论,后来读者看到该段落时评论以弹幕形式飘过,形成一种"边读边聊"的共读体验。** 这是它作为网文平台的独特壁垒,因为这种段落级互动需要海量用户在同一本书的同一位置留下内容,冷启动极难。

我们不与之竞争的原因是:书域定位公版书(四大名著、鲁迅全集等),目标用户读的是已沉淀的经典,不追求连载追更和弹幕互动,而追求"读懂"。这是两个不同的需求方向。

### 微信读书:社交裂变是引擎,但公版书的 AI 问答不是它的重点

**微信读书的核心优势是微信社交链——好友在读、读书排行榜、组队抽无限卡,让阅读从个人行为变成社交行为。** 搭配出版书 + 公版书 + 网文的混合书库,它是三个竞品中书库最全面的。

我们不与之竞争的原因是:微信读书的 AI 功能(朗读、推荐)服务于"让用户多读"而非"帮用户读懂某一段落"。书域要做的 RAG 问答——选中一句文言文问"这四个字在这里是什么意思"——需要把整本书逐段向量化并按上下文检索,这不是通用读书 App 的投入方向,但正是结课设计的亮点。

### 番茄小说:免费模式压倒一切,但阅读体验本身被广告打断

**番茄小说的核心逻辑是"用看广告的时间换取免费阅读",通过金币体系绑定用户时长。** 它的送书/限免/金币签到机制使大量对价格敏感的用户涌入。

我们不与之竞争的原因是:番茄的内容以网文和轻小说为主,阅读器内穿插广告(阅读页底部横幅、章节间插屏),这种"免费 + 广告"模式与书域的"沉浸式读经典 + AI 提问"是两种完全不同的产品哲学。需要清净阅读环境、愿意深入理解文本的用户,不是番茄的目标用户。

## 三、书域的差异点

**书域在两个维度上不同于三个竞品:**

1. **教学完整性——全流程开源 + 一本书**:书域是一个教学项目而非商业产品,每个 MVP 有完整源码(Spring Boot / Android Compose / RabbitMQ / Spring AI)和配套文档书,所有架构决策有根据可查。对需要学习全栈开发的学生和开发者来说,这不是一个"黑盒 App",而是一份可运行的教材。

2. **RAG 读书问答——嵌入阅读器的"划词即问"**:书域的 AI 不是推荐算法,不是角色扮演,而是围绕书籍内容本身的知识检索——章节预先向量化入库,读者选中一段文字即可提问,AI 从向量库检索相关上下文后引用原文回答。这个功能直接嵌入阅读器,不打断阅读流,是整个平台最出彩的技术点。
