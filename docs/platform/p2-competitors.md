# P2 竞品分析

> **结论先行**:起点读书/微信读书/番茄小说各占一个生态位——网文付费、社交阅读、广告换免费。书域不与它们正面竞争,而是在它们不投入的方向做差异:全流程开源教学 + 嵌入阅读器的 RAG 读书问答。

## 一、功能对比表

| 维度 | 起点读书 | 微信读书 | 番茄小说 | **书域(我们)** |
| --- | --- | --- | --- | --- |
| 书架 | 收藏 + 追更 + 进度同步 | 书架 + 分组 + 跨设备 | 书架 + 离线 + 阅读收益 | Room 离线 + JWT 跨设备同步 |

## 二、竞品逐一分析

### 起点读书

**起点将段落级评论做成"本章说"——读者看到任意段落都能看到前人的弹幕式评论,形成共读体验。** 它的壁垒是海量活跃用户在同一位置留内容,冷启动极难。书域做公版书,用户追求"读懂"而非"追更弹幕",是不同方向。

### 微信读书

**微信读书用社交链(好友在读、排行榜、组队抽卡)驱动阅读,书库里三者最全。** 它的 AI(朗读、推荐)服务于"让用户多读",不做逐段向量化和按章节上下文检索——选中文言文问"这四个字在这里是什么意思"不是微信读书的投入方向。这正是书域的差异点。

### 番茄小说

**番茄用"看广告换免费阅读"的金币体系绑定用户时长,牺牲了沉浸感。** 阅读器内穿插广告(底部横幅、章节间插屏),内容以网文为主。书域做的是沉浸式读经典 + AI 提问,不需要广告,是两种产品哲学。

## 三、书域的差异点

**书域在两个维度上不同于三个竞品:**

1. **教学完整性——全流程开源 + 配套书**:不是黑盒 App,而是可运行教材——全栈源码(Spring Boot + Compose + RabbitMQ + Spring AI)+ 架构文档,每个决策有根据可查。
2. **RAG 读书问答——嵌入阅读器的划词即问**:章节逐段向量化入库,读者选中即问,AI 从当前章节检索上下文后引用原文回答。三个竞品没有一个把这个作为核心功能。
