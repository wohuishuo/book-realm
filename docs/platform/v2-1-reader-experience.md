# v2.1 阅读体验 MVP 工单

> **结论先行**:v2.1 只解决一个问题——BookRealm 从“能读”升级到“像一个真实阅读 App”。本轮不做后端新服务,先把 Android 端的书架、详情页、阅读器工具层和阅读设置做扎实。

## 一、一分钟说明

v2.1 完成后,用户打开 App 应该能:

在书架看到最近阅读和自己的书;点进书籍详情能看到简介、标签、目录和继续阅读;进入阅读页后,默认只看正文,点击屏幕才显示工具层;底部可以打开目录、调整字号/行距/主题、请求 AI 和听书入口。

这一步做完,BookRealm 才从“课程 Demo”走向“阅读产品”。

## 二、范围裁剪

**结论:本轮只改体验骨架,不抢跑复杂能力。**

| 做 | 不做 |
| --- | --- |
| 书架最近阅读 | 商业推荐流 |
| 书籍详情长页 | 书评/社区完整系统 |
| 阅读页顶部/底部工具层 | 复杂翻页动画 |
| 字号、行距、主题 | 自定义字体文件 |
| 目录跳转 | 大规模目录搜索 |
| AI/听书入口位置优化 | 完整 TTS 服务 |

## 三、页面验收

### 1. 书架页

必须有:

- 最近阅读卡片;
- 书架列表;
- 空状态;
- 每本书显示书名、作者、简介、阅读状态;
- 搜索/书城入口仍可用。

### 2. 书籍详情页

必须有:

- 封面占位;
- 书名、作者、标签;
- 简介;
- 加入书架/继续阅读;
- 目录列表;
- AI 摘要入口位置预留。

### 3. 阅读页

必须有:

- 点击正文显示/隐藏工具层;
- 顶部:返回、章节名、更多;
- 底部:目录、主题、字号、AI、听;
- 字号调整;
- 行距调整;
- 浅色/护眼/夜间主题;
- 目录底板;
- AI 结果卡片不遮挡正文。

## 四、实现顺序

1. 改 `AppRoot.kt`,先把页面结构拆清楚;
2. 加阅读页本地状态:工具层、目录底板、主题、行距;
3. 构建 `assembleDebug`;
4. 更新平台书实战章;
5. 真机安装验证。

## 五、完成定义

v2.1 第一轮完成必须满足:

1. `./gradlew assembleDebug` 通过;
2. App 可登录、搜书、加入书架、打开章节;
3. 阅读页点击正文能显示/隐藏工具层;
4. 字号、行距、主题能即时变化;
5. 目录底板能打开并跳章节;
6. 平台书记录本轮设计和真实代码。
