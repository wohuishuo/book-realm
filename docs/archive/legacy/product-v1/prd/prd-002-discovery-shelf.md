# PRD-002 找书与书架

> **结论先行**:读者需要快速找到一本书并保存到个人书架,书架与书城必须表达两个不同任务。

## 用户问题

书城用于发现全站内容,书架用于回到自己已经选择的书。如果两个搜索入口和状态混在一起,读者无法判断自己在搜全站还是个人收藏。

## 用户旅程

```text
进入书城 → 搜索书名/作者 → 打开详情 → 查看目录
→ 加入书架 → 返回书架可见 → 可移出书架
```

## 范围

- 书城列表、搜索、书籍详情和章节目录。
- Room 本地书架,重启后保留。
- 书架本地搜索和独立书城入口。
- 加入、查看和移出书架。
- 加载、空、错误和重试状态。

## 不做

商业推荐、支付会员、版权运营和复杂书单社交不进入当前版本。

## 验收标准

- 搜索“西游”能找到并打开《西游记》。
- 加入书架后重启 App 仍可见。
- 书架搜索只搜索已加入的书;书城搜索全站内容。
- 移出书架后列表和本地状态一致。
- 网络失败时页面给出可理解错误和重试入口。

## 当前证据

书库服务已提供书籍、详情和章节 API;Android 已实现书城、详情、Room 书架、书架搜索和移出操作。缺口是把整条旅程纳入自动点击回归。
