# PRD-003 阅读连续性

> **结论先行**:读者需要顺畅打开章节、调整阅读样式并在离开后回到正确位置,阅读连续性比新增入口更重要。

## 用户问题

阅读器如果丢失位置、返回路径混乱或离线即不可用,读者无法形成稳定阅读习惯。设置只有在重启后仍保留才算真实能力。

## 用户旅程

```text
从书架/详情打开章节 → 阅读段落 → 调整主题/字号/行距
→ 离开 → 再次打开 → 恢复章节与位置 → 网络失败时使用缓存
```

## 范围

- 章节和段落渲染。
- 主题、字号、行距及其持久化。
- 阅读位置本地保存和服务端进度上报。
- 章节缓存与离线回退。
- 从书架和详情进入时保持正确返回路径。
- 阅读工具栏、系统栏和 AI 临时界面的显示规则。

## 不做

复杂排版引擎、竖排、跨设备实时同步和完整 EPUB 兼容暂不进入当前版本。

## 验收标准

- 能打开种子书章节并稳定阅读段落。
- 修改主题、字号和行距后重启仍生效。
- 退出再进入能恢复上次章节和阅读位置。
- 无网络时已缓存章节仍可阅读。
- 从书架进入返回书架,从详情目录进入返回详情。
- 进度上报失败不阻断阅读。

## 当前证据

Android 已实现章节阅读、样式持久化、进度、缓存和返回路径修正;统计服务支持进度 upsert。缺口是真实设备上的完整自动点击链路与持续回归。

## 关联

- 能力:Android、书库、统计
- 质量门:Android 单元测试、adb 主旅程、进度 API 集成测试
