# PRD-005 AI 原文理解

> **结论先行**:AI 必须帮助读者理解当前原文,回答要带可定位依据,不能只是离开阅读场景的通用聊天框。

## 用户问题

读者遇到陌生概念或情节时需要即时解释。通用模型容易脱离书中内容回答,而无法回到引用位置的答案也难以核查。

## 用户旅程

```text
选中原文/打开 AI → 请求摘要或输入问题 → 检索相关段落
→ 生成带引用回答 → 点击引用回到原文 → 保留必要历史
```

## 范围

- 章节摘要和围绕书籍/章节的问答。
- 先检索原文,再生成回答。
- 回答展示引用段落和是否使用模型。
- 无模型 Key、无检索结果和网络失败时可解释降级。
- 引用跳回原文。
- 最小 AI 历史入口。

## 不做

角色扮演、续写、开放式智能体、复杂知识库后台和不可控长会话不进入当前版本。

## 验收标准

- 有相关内容时回答包含可核查原文引用。
- 章节过滤生效,不会把无关章节当作依据。
- 无 `DEEPSEEK_API_KEY` 时服务仍可启动并给出明确降级结果。
- 空检索不会伪装成“有原文依据”。
- 点击引用可以定位到对应章节段落。
- AI 不可用时阅读主流程不崩溃。

## 当前证据

AI 服务已实现摘要、索引、检索和问答;Android 已提供阅读内临时 AI 窗口。引用跳转、历史记录和检索算法的独立测试仍是缺口。

## 关联

- 能力:Android、AI、书库
- 质量门:RAG 排序单测、章节过滤测试、降级测试、引用跳转 UI 验收
