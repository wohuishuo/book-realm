# PRD-004 阅读标记与互动

> **结论先行**:读者需要围绕原文划线、记录想法和查看互动,并能再次找到、修改或删除自己的阅读痕迹。

## 用户问题

只支持“创建划线”不是完整能力。读者还需要识别已划线内容、管理自己的记录,并确保其他用户不能操作这些数据。

## 用户旅程

```text
长按段落 → 选择范围 → 划线/写想法/发布段评
→ 再次点击标记 → 查看或删除 → 在“我的记录”中重新找到
```

## 范围

- 单段和连续段落范围选择。
- 划线、笔记、段评及点赞/取消点赞。
- 已标记段落视觉状态和轻量操作面板。
- 删除或更新自己的记录。
- 我的笔记、我的段评入口。
- 所有个人数据操作强制服务端鉴权。

## 不做

复杂社区、关注关系、私信、内容审核后台和商业社交推荐不进入当前版本。

## 验收标准

- 长按段落后可以创建划线并在重新打开章节后看到。
- 已划线段落可以写笔记、发布段评或删除。
- 点赞重复操作保持幂等,计数不会异常累加。
- 用户不能查看或删除他人的私有标记。
- 我的笔记和我的段评有稳定入口,点击可回到原文。

## 当前证据

书库服务已实现标记、笔记、段评和点赞接口;Android 已接入创建、显示、删除和互动。个人列表入口、回到原文和统一鉴权尚未完成,因此仍是部分产品化。
