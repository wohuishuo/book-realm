# PRD-001 身份与会话

> **结论先行**:读者需要安全登录并持续保持会话;所有用户数据操作必须由服务端从可信令牌确定身份。

## 用户问题

读者不应在每次打开 App 时重新登录,也不能因为客户端可修改 `userId` 而访问或删除他人的阅读数据。

## 用户旅程

```text
输入账号密码 → 登录成功 → App 保存会话 → 重启后仍登录
→ 访问个人书架/标记/进度 → 服务端验证令牌中的身份
```

## 范围

- 注册、登录、退出和当前用户。
- JWT 保存与请求头自动携带。
- 令牌过期、篡改和缺失时返回明确状态。
- 用户数据接口从服务端身份取用户 ID。
- 登录成功发布事件,统计服务可旁路消费。

## 不做

OAuth、多因素认证、找回密码和商业账号体系暂不进入当前版本。

## 验收标准

- 正确账号可以登录,错误凭据不暴露账号是否存在。
- App 重启后在有效期内保持登录。
- 无令牌访问受保护接口返回 401。
- 用户 A 不能读取、修改或删除用户 B 的数据。
- 公开书籍读取接口不因鉴权改造被错误阻断。
- 登录统计失败不影响登录主链路。

## 当前证据

用户中心已实现 BCrypt、JWT、当前用户和登录事件;Android 已保存并携带 JWT。平台 ADR-001 已指出其他后端尚未统一验签,因此本 PRD 状态是“功能已实现,安全验收未完成”。
