# 序言:BookRealm 是什么

> **结论先行**:BookRealm 是一个开源跨平台阅读平台,也是一本讲清它如何做出来的工程书。平台已经跑通 v1:Android App 登录、找书、阅读、统计进度,并用 AI 基于原文做摘要和问答。

## 为什么做这个平台

**结论:我们想把课程项目做成一个别人也能理解、运行和复用的真实工程。**

根据有三点:

1. **它有真实产品主线**:读者不是看架构图,而是在手机上登录、找书、阅读和提问。
2. **它覆盖现代工程能力**:Android 客户端、Spring Boot 服务、JWT、MySQL、RabbitMQ、RAG、DeepSeek、文档和 Git 协作都在同一个平台里。
3. **它适合拆开学习**:用户中心、书库、App、统计、AI 服务都有清晰边界,每个仓库都能独立运行。

例子:如果只想学 RAG,可以直接看 AI 服务;如果只想学 Compose 客户端,可以直接看阅读 App;如果想理解完整生命周期,就按本书从平台篇读到实战篇。

## 这本书放什么

**结论:平台书负责讲清全局,代码仓负责交付各自模块。**

本书放需求、用例、领域模型、架构、技术图鉴、实战讲解和真实踩坑。各代码仓保留 README、design、notes 三类轻文档,让使用者能快速跑起来;完整教学集中在这里,避免知识散落。

## 写作规则

**结论:这本书尽量让读者少绕路。**

每一节先讲结论,再讲根据和例子。我们不要求读者从代码缝里猜意图,也不把“我当时怎么摸索”的过程当主线。读者应该在一分钟内知道本节要解决什么问题,再决定是否继续看细节。
