## 什么时候写 ADR

- 改变服务边界、数据归属或跨仓契约。
- 引入新的基础设施、共享库或安全模型。
- 存在两种以上合理方案,且选择会长期影响维护。

实现细节、普通 Bug 和一次性任务直接进入 Issue;ADR 被接受后,相关 PRD 和 Issue 必须链接它。
