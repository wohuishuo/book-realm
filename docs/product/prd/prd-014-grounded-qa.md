# PRD-014 AI 原文问答

status: Partial  
owner: AI + Reader + Library

## Why
读者遇到不理解的内容时需要基于书中原文获得解释。

## Problem
通用回答可能脱离当前书籍,无法核查引用。

## Goal
先检索书中段落,再生成带原文依据的回答并支持引用跳转。

## Journey
选中原文 -> 输入问题 -> 检索段落 -> 查看回答和引用 -> 跳回原文

## Non-goals
不做开放式智能体、角色扮演和无限长会话。

## Acceptance
- 回答标记是否使用原文依据。
- 章节过滤和空检索处理正确。
- 点击引用可以定位到原文段落。
