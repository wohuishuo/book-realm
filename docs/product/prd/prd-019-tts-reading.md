# PRD-019 听书与 TTS

status: Proposed  
owner: Reader + AI

## Why
用户需要在通勤、家务或视觉疲劳时继续阅读。

## Problem
当前正文只能视觉阅读，离开屏幕后阅读旅程中断。

## Goal
用户可从当前段开始播放、暂停、跳转和调速，并保持文字与语音位置一致。

## Journey
打开章节 -> 点击听书 -> 从当前段播放 -> 调整速度 -> 暂停 -> 下次从该位置继续

## Non-goals
不制作真人有声书，不在首版提供声音市场。

## Acceptance
- 播放位置与当前段落同步。
- 来电、耳机断开和应用退后台时正确暂停。
- 服务不可用时阅读正文不受影响。
