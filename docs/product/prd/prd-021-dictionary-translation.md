# PRD-021 词典与翻译

status: Proposed  
owner: Reader + AI

## Why
生词查询不应迫使用户离开阅读上下文。

## Problem
选中文字后缺少释义、翻译和回到原文的连续操作。

## Goal
用户选择词语或句子后可在阅读页内查看释义或翻译。

## Journey
长按文字 -> 调整选择范围 -> 点击词典或翻译 -> 查看结果 -> 关闭并继续阅读

## Non-goals
不建设自有权威词典库，不提供专业人工翻译。

## Acceptance
- 结果面板不遮挡所选原文。
- 查询失败可重试且不改变选择范围。
- 用户可复制结果或保存为笔记。
