# PRD-022 内容管理

status: Proposed  
owner: Library + Web Admin

## Why
运营人员需要独立维护书籍、章节和发布状态。

## Problem
内容依赖数据库脚本或开发人员处理，无法可靠审校和发布。

## Goal
管理员可创建、编辑、预览、发布和下架书籍及章节。

## Journey
登录管理端 -> 新建书籍 -> 编辑章节 -> 预览 -> 发布 -> 在书库可见

## Non-goals
不做复杂版权结算和多人实时协作编辑。

## Acceptance
- 草稿对普通用户不可见。
- 发布前校验必填元数据与章节顺序。
- 发布、下架和修改留下审计记录。
