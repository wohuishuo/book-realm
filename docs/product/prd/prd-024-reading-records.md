# PRD-024 阅读记录与个人资料

status: Proposed  
owner: Reader + Stats

## Why
用户需要回顾自己读过什么以及形成了哪些笔记。

## Problem
进度、笔记和统计分散在不同功能，缺少统一个人入口。

## Goal
个人页展示最近阅读、阅读进度、笔记入口和基础统计。

## Journey
打开个人页 -> 查看最近阅读 -> 进入一本书的记录 -> 继续阅读或查看笔记

## Non-goals
不做公开排行榜和强社交比较。

## Acceptance
- 最近阅读按最后活动时间排序。
- 删除记录前明确说明对进度和笔记的影响。
- 无记录时提供回到书城的单一主操作。
