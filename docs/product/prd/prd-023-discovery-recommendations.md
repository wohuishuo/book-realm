# PRD-023 阅读发现与推荐

status: Proposed  
owner: Library + Stats

## Why
用户需要低成本发现下一本值得读的书。

## Problem
只有关键词搜索，用户不知道书名时难以发现内容。

## Goal
书城按分类、热门和基于阅读记录的推荐提供可解释的发现入口。

## Journey
打开书城 -> 浏览推荐 -> 查看推荐原因 -> 打开详情 -> 加入书架

## Non-goals
不以无限信息流和广告点击率为目标。

## Acceptance
- 新用户有不依赖历史数据的推荐。
- 个性化推荐可关闭并说明主要依据。
- 推荐失败时回退到分类与热门列表。
