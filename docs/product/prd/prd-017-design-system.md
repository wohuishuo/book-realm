# PRD-017 UI 设计系统

status: Done  
owner: Reader App

## Why
多个页面需要一致的颜色、间距、组件状态和交互规则。

## Problem
页面各自定义样式会产生重复组件和行为漂移。

## Goal
建立设计令牌、基础组件和阅读器专用组件。

## Journey
开发页面 -> 选择现有令牌/组件 -> 补齐状态 -> Preview/真机验收

## Non-goals
不追求复制任何商业 App 的完整视觉。

## Acceptance
- 颜色、尺寸、形状和动效有单一代码来源。
- 常用输入、按钮、卡片和状态组件可复用。
- 阅读器遵守独立 UI Rules。
