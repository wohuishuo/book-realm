# PRD-011 阅读笔记

status: Partial  
owner: Reader + Library

## Why
读者需要把想法绑定到具体原文并重新找到。

## Problem
笔记只有创建入口但没有统一列表和原文跳转时不完整。

## Goal
支持创建、编辑、删除、列表和回到原文。

## Journey
选中原文 -> 写笔记 -> 打开我的笔记 -> 点击 -> 回到原文

## Non-goals
不做复杂知识图谱和公开笔记社区。

## Acceptance
- 笔记与用户、书、章节、段落绑定。
- 用户只能管理自己的笔记。
- 我的笔记列表和原文跳转可用。
