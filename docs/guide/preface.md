# 序言:超级项目是什么

> **结论先行**:「书域」是一个**多 MVP 超级项目**——5 个独立完整、互相咬合的服务组成一个电子书平台;每个 MVP 一个仓库一本书,本仓是枢纽,放**方法正本与平台总纲**。

## 为什么做成"多 MVP"

**根据**:三个理由叠加——

1. **官方要求**:《移动互联系统分析与设计结课设计》要求 Server+Client、领域模型(Bounded Context)、微服务+消息队列+AI 说明——多 MVP 平台正是高分卷的形状;
2. **风险控制**:每个 MVP 独立可演示,时间不够按砍单顺序砍,平台依然完整;
3. **已有资产**:前作[用户中心](https://wohuishuo.github.io/user-center-team-project/)已完整跑通,直接当认证微服务复用——第一块积木是现成的。

**例子**:老师《专业训练课题》的原题(登录事件 → RabbitMQ → 日志+统计微服务),在我们的地图里就是 MVP-3,用户中心加一行"发布事件"即接上。

## 这本平台书放什么(与各 MVP 仓的分工)

**结论**:这本书讲**一切**——方法、设计(P 阶段)、以及[实战篇](/project/)里每个 MVP 的完整讲解(嵌真实代码、记真实坑)。**各 MVP 仓只放代码 + 三个轻文档(README/design/notes)**,教学不散落;读懂平台,只需读这一本书。
