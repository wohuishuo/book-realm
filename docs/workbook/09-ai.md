# 09 AI 摘要与原文问答

阅读 AI 的价值不是自由聊天，而是帮助用户理解当前书籍，并能指出答案依据。模型失败时，正文阅读必须继续可用。

## 两条能力

章节摘要接收受限长度的章节内容并返回结构化结果。原文问答先检索相关段落，再把段落和问题交给模型，回答携带可跳转引用。

## 安全边界

模型密钥只存在服务端；限制输入长度和调用频率；不把未检索内容伪装成原文结论；降级状态使用稳定错误码。

## 完成证据

Controller 测试覆盖成功和降级；Cucumber 通过真实 HTTP 获取非空回答；Android 能从引用跳回段落。相关 [ADR-010](/architecture/adr/adr-010-grounded-rag)。
