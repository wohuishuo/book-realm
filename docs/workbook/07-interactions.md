# 07 划线、笔记与段评

阅读互动都从稳定的原文锚点开始。只保存屏幕坐标或字符高亮颜色，会在排版变化后失去定位。

## 模型

划线和笔记属于用户私有标记；段评是公开互动；点赞是用户与段评的唯一关系。它们可共享 book/chapter/paragraph 锚点，但权限和生命周期不同。

## UI

文字选择采用微信读书模式：紧凑操作栏提供划线、笔记、复制、词典和 AI；二级面板选择颜色。入口必须使用 [Pattern Library](/ui/patterns) 中的批准组件。

## 完成证据

重开章节仍能定位划线；笔记可反向跳回原文；重复点赞不重复计数；删除权限由服务端验证。
