# BookRealm 实战书

这本书用一个真实的 Spring Web + Android 阅读平台，学习如何把产品判断、架构决策、代码实现和自动验证连成闭环。它不是项目日志，也不复述旧方案；每章都从当前代码和当前规格出发。

## 两个入口

- **实战书**：适合顺序阅读，解释为什么做、如何拆、怎样验证。
- **项目管理台**：适合工作时查询，保存 [PRD](/product/prd/)、[ADR](/architecture/adr/)、[Feature](/specs/) 和 [Harness](/quality/harness)。
