# 10 设计系统与 UI Loop

设计系统的作用是消除随机性。Agent 不根据每张页面临时决定颜色、间距和栏高，而是组合经过预览的组件。

## 来源规则

书架、阅读器、选择菜单和阅读设置优先参考微信读书；AI 对话和复杂目录在微信读书未覆盖时参考起点。参考的是交互模式，不复制品牌。

## 实现闭环

先读 PRD Journey，再选择模式和组件；缺少组件时先补 token、组件与 Preview，之后才进入业务页面。CI 拦截裸颜色、行内样式和页面私有按钮。

## 完成证据

设计系统中的每个组件展示浅色、深色、禁用、加载和长文本状态；页面只引用 `BrTheme`、`BrDimens`、`BrTypography` 与 `Br*` 组件。完整规则见 [Design System](/ui/design-system)。
